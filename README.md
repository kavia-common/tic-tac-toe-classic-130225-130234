# tic-tac-toe-classic-130225-130234

Tic Tac Toe mobile app built with React Native (Expo).
- Modes: Player vs Player (PvP), Player vs AI (PvAI)
- 3x3 grid, winner highlighting
- Status bar shows current turn, winner, or draw
- Controls: Replay (reset the board) and Reset Scores (clears scoreboard)
- Local (in-memory) score tracking for X, O, and Draws
- Modern minimalistic light theme
- Color palette: Primary #1976d2, Accent #ff4081, Secondary #90caf9

Project entry: tic_tac_toe_frontend/App.tsx

To run:
- npm install
- npm start
